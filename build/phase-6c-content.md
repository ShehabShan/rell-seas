## 1. `#read-first-rules` — PINNED

Paste-ready text (the disclaimer line is kept exactly as pinned on the live server):

```
FAN-RUN — This is a fan-run community, not official. Not affiliated with the RELL Seas developers. No official assets used here. Treat everything as community discussion unless a Keeper post links a primary source.

No reuse of official game art or logos — member art and text only.

Welcome aboard. Six rules keep this ship steady:

1. Argue with evidence, never insults. Compare and disagree all you like, but back it up. Name-calling gets moved or removed.
2. Label rumors honestly. Say CONFIRMED (with a source link) or RUMOR (no source). Unsourced claims restated as fact will get a rumor tag.
3. No harassment, hate, or dogpiling. Tired of the chant? Step away, don't swing at the crew. Report it and a Keeper will look on the next check-in.
4. English only. This keeps one small crew able to read everything. (Non-English speakers: see #welcome-in-pt-fr-es.)
5. No scams, ever. Don't post giveaway links, login links, or "free" offers. Keepers will never ask for your password or token. If it smells fishy, report it.
6. Post in the right room. Salt goes in #watch-deck, hope in #lantern-room, claims in #receipts-and-rumors. Keepers may move or label off-course posts. Appeals are always welcome through the report path below.

Solo sailors stand equal here. Crewed or solo, you're crew. (React for the Solo Banner flair if you sail alone — details in #finder.)

Looking for players in your language? Communities in other languages exist, but this server runs English-only and doesn't officially link any. Ask a Keeper if you need pointing in the right direction.

Something wrong? Message a Keeper directly, or reply in a thread in #scam-watch-and-report. Both land in the same queue, cleared at the next check-in. (A /report command may be added later — this path will stay just as easy.)
```

## 3. Channel guidelines

### `#finder` (forum) — PINNED

```
Find your crew — or fly solo with pride.

Open a thread with: playstyle (fighter / trader / explorer / chill) + faction if you have one + what you're after (crew, friend, rival, mentor).

Solo? Add the Solo Banner flair to your post. Solo sailors stand equal — no crew pressure here.

Threads close after 7 quiet days. Still looking? Just post again. Lost-friend reunions welcome — title it "Reunion:" plus your old crew name.
```

### `#help-desk` (forum) — PINNED

```
One question, one thread, one checkable answer.

Ask anything: testing access, platforms, safety checks ("is this link real?"). Answers should come with a source or say "not confirmed."

Device tips welcome — if you've played on similar hardware, say so. Guesses dressed as specs will get an "uncertain" tag. That's normal here.
```

### `#receipts-and-rumors` — PINNED

```
Detective desk. Every claim starts here.

Start your post with one of these:
- CONFIRMED + link to the source, or
- RUMOR + where you heard it (or "no source").

Argue with evidence, never insults. Respectful doubt is never deleted — the worst it gets is a rumor tag. Member posts that belong on the milestone board get moved there by a Keeper, with credit.
```

### `#introductions` — PINNED

```
New aboard? Say hello in one breath:

Callsign / where you sailed from / solo or looking / one thing you love about the ocean.

Example: "Miri / Shindo enjoyer / looking / I just want a ship that feels like home."

Reactions guaranteed. Questions can wait — this room is for hellos.
```

### `#tenure-and-returns` — PINNED

```
Leaving and returning are both honorable.

Tenure honors live here — day-zero watchers, longtime sailors, both-Shinobi-Lives sailors. Claimed, never invented: say what's true, with credit.

Coming back after time away? Post a return note. Reunion boards for lost-friend groups welcome. Return doors open alongside real milestones only — no fake fanfare.
```

### `#patient-craft` — PINNED

```
Waiting, made into craft.

Patience notes, sea-myths, slang for the glossary — with your name on it. New entries need something real attached: a thought-through idea, a source, a story.

Curated slowly by Keepers and Elders. Thin posts wait for more substance; good ones get featured with author credit.
```

```
Creators as kin, mirrored fast and credited.

Sourced creator material, shared in English with a credit frame: who made it, where it lives, what it shows. Corrections from creators are always welcome and applied quickly.
```
